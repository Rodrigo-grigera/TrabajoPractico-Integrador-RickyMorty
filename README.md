# Rick & Morty — Trabajo Práctico Integrador

Aplicación web desarrollada como trabajo práctico integrador, utilizando la Rick and Morty API para consultar, mostrar y filtrar personajes de la serie.

El proyecto permite navegar entre las diferentes páginas de personajes, buscar por nombre y filtrar según el estado del personaje.

Funcionalidades:
-Visualización de personajes obtenidos desde la API.
-Búsqueda de personajes por nombre.
-Filtrado por estado: Vivos / Muertos / Desconocidos.
-Botón para restablecer los filtros.
-Navegación entre páginas de personajes.
-Deshabilitación de los botones de navegación cuando corresponde.
-Modal con información detallada del personaje.
-Efectos visuales y estilos personalizados.
-Diseño adaptable a diferentes tamaños de pantalla.

Tecnologías utilizadas:
-HTML5.
-CSS3.
-JavaScript.
-Fetch API.
-Rick and Morty API.
-Git.
-GitHub.

La aplicación utiliza la API para realizar consultas dinámicas según la página, el nombre y el estado seleccionado.

Búsqueda y filtros:
La aplicación permite buscar personajes ingresando su nombre y consultar los resultados directamente desde la API.

También se pueden filtrar los personajes según su estado:

-Alive: personajes vivos.
-Dead: personajes muertos.
-Unknown: personajes cuyo estado se desconoce.
-Los filtros pueden restablecerse utilizando el botón Reset.

Paginación:
La aplicación utiliza la información proporcionada por la API para navegar entre las diferentes páginas de resultados.

Los botones Anterior y Siguiente se habilitan o deshabilitan automáticamente según la página actual.

Información del personaje
Al seleccionar una carta se abre un modal con información adicional del personaje, incluyendo:

Imagen.
Nombre.
Estado.
Especie.
Origen.
El modal puede cerrarse utilizando el botón correspondiente.
